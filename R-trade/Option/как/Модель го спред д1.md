## 0. Модель: <"Дельта-Хедж" (1-3 дня, MANTA)> 🚀 (Финальная Редакция)

---

### 1. Инструменты и Объем

| Параметр | Значение / Описание |
| :--- | :--- |
| **Базовый Актив** | **MANTA USDT-M Perpetual Futures** (для определения цены). |
| **Инструмент** | **Вертикальный Дебетный Спред (VDS)** на опционах **MANTA**. |
| **Риск/Лот** | **Супер маленький**, за счет VDS и выбора MANTA. Минимальный лот (1 спред) на каждую позицию. |
| **Нагрузка** | Общая нагрузка маржи (ГО) на всю сетку: Не более **15%** от депозита. |

---

### 2. Вход и Пирамидинг (Лесенка)

| Параметр | Значение / Описание |
| :--- | :--- |
| **Направление** | **Строго на продолжение** (По тренду), определенному последней свечой D1. **Запрет** на усреднение против тренда. |
| **Экспирация** | **Гибкая:** 6 – 72 часа (1, 2 или 3 дня). |
| **Лесенка (Интрадей)** | **Пирамидинг:** Дополнительные спреды открываются **внутри дня** (H1/H4) только **в сторону тренда** с шагом **0.5 ATR (D1)** от предыдущего входа. |
| **Лимит Позиций** | **Максимум 3 спреда** в одной торговой серии (лесенке) до ее фиксации или истечения. |
| **Страйки** | АТМ/чуть ОТМ для максимальной **Дельты** (чувствительности). |

---

### 3. Управление Позицией и Фиксация

| Параметр                      | Значение / Описание                                                                                                                                                                                                                                                                                 |
| :---------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Цель Прибыли**              | Фиксация **всей сетки целиком** при достижении целевой прибыли (например, +50% от суммарного дебета).                                                                                                                                                                                               |
| **Метод 1 (Основной Замок)**  | **Замок Опционами (Iron Condor):** <br>Превращение прибыльной VDS-сетки в Айрон Кондор путем продажи противоположного спреда. Исполнение **Лимитным Ордером**.                                                                                                                                      |
| **Метод 2 (Резервный Замок)** | **Замок Фьючерсом:** При проблемах с ликвидностью опционов ($F_{\text{MANTA}}$) прибыль фиксируется **продажей/покупкой** фьючерса на MANTA в размере, равном **общей Дельте** опционной сетки ($\Delta_{\text{Сетка}}$), для немедленной нейтрализации. <br>→ *Помните: это временно увеличит ГО.* |
| **Критический Убыток**        | **Немедленно прекратить набор** при развороте цены (пересечение точки безубыточности первого спреда).                                                                                                                                                                                               |
| **Убыточная Сетка**           | Убыточные спреды **не усредняются** и **не роллируются**, им дают истечь. Убыток ограничен уплаченным дебетом.                                                                                                                                                                                      |
