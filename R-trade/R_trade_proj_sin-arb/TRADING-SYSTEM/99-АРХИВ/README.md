## Как вернуть
```bash
git mv "99-АРХИВ/<путь>" "<путь>"      # из папки TRADING-SYSTEM
```
После возврата прогнать проверку ссылок (скрипт перестройки — в истории коммита) и добавить файл в `00-INDEX.md`.

`Дашборд.canvas` хранит пути старых карточек: после переноса он может показывать пустые узлы.
