# Стресс «ETH против корзины»

P&L T+0 (Блэк–Шоулз при текущей IV) относительно «сейчас», когда базы двигаются **по-разному**:
1. только [[ETH]] (корзина стоит);
2. только корзина ([[BTC]], [[SOL]], [[MNT]]…; ETH стоит);
3. ETH +m / корзина −m — главный риск спреда «шорт ETH против лонга корзины»;
4. согласованно по β (ETH m, база β·m) — см. [[Бета к ETH]].

Ходы: −20, −10, −5, +5, +10, +20 %. Обычный payoff двигает всё на один % и расхождение не видит — [[Payoff и безубыток]].
Где: [[Вкладка Портфель]] → «Весь портфель». Код: `_shock` в [[mod portfolio_book]].
[[Portfolio Margin]] разные монеты не неттит — спред маржинится как две направленные позиции.
