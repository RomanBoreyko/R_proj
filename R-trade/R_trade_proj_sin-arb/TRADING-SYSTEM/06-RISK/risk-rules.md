# Правила риска — оператор спреда SOXL / SOXS

← [00-INDEX](../00-INDEX.md) · [Спецификация](../03-STRATEGIES/SPREAD-оператор-SOXL-SOXS.md) · [Чек-лист дня](../08-operator/чек-лист-дня.md) · уроки: [ОС-08](../13-LEARNING/Оператор%20спреда/ОС-08%20Риски%20и%20уроки.md)

## Запреты
```
❌ Голые непокрытые шорты. Шорт — только как нога конструкции с закрытым хвостом
❌ Ликвидация недопустима: запас до ликвидации (эквити − MM) < 25% эквити — только сокращение
❌ Новые ноги при IM > 50%
❌ Хеджировать другой монетой ради экономии маржи (Portfolio Margin не зачитывает монеты)
❌ Выкупать проданные опционы «чтобы освободить маржу», не проверив сценарий Bybit
❌ Продавать то, чего нет на балансе (на споте это открывает займ-шорт)
```

## Рабочие лимиты
```
✔ IM ≤ 50%. ≥ 40% — новых ног не добавлять
✔ Δ SOX до закрытия США — коридор ±$40 (по зеркалу, опционы учтены)
✔ Δ после закрытия — хедж готов к 23:00 по Киеву
✔ Тета книги не хуже −$10 в сутки
✔ Тета страховки ≤ 30–40% дохода скальпа за 7 дней
✔ Опционы-страховка: экспирация ≥ 2 недель, недельные не держать
```

## Исполнение
```
✔ После каждой сделки — сверка стороны, инструмента и дельты по деску (не по MetaScalp)
✔ Скальп — мейкер-лимитками
✔ Большую книгу резать пропорционально всеми ногами (по 25%), не по одной
✔ В дни событий (CPI, ФРС, отчёты NVDA/AVGO/TSM/MU) коридор шире, опционы не докупать на скачке IV
```
