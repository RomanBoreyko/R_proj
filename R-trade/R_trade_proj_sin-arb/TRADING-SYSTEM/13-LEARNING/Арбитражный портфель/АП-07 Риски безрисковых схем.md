# 7. Риски «безрисковых» схем — пределы арбитража

← [[АП-06 Механика Bybit]] · [[АП-00 Карта курса]] · далее → [[АП-08 Как мерить результат]]

## Идея
Учебный арбитраж — без денег и без риска. Реальный — с маржой, временем и людьми.
Классика: Shleifer & Vishny, «The Limits of Arbitrage» (1997) — арбитраж ограничен капиталом: расхождение может **сначала вырасти**, а маржин-колл придёт раньше схождения. Хрестоматийный пример — крах фонда LTCM (1998): конвергентные сделки с большим плечом.

## Список рисков
| Риск | Как проявляется | Защита |
|---|---|---|
| **Маржа до схождения** | спред расширился → нереализованный минус → маржин-колл/ликвидация до экспирации | малое плечо, запас EQ/MM ≥ 1.5×, Portfolio Margin учитывает связку |
| **Базисный** | XAUT/XAU, спот/перп расходятся сильнее исторического | стоп по спреду (у золота — «стоп» на 166д), размер от худшего расхождения |
| **Фандинг** | ставка развернулась → кэрри платит | смотреть средний за 7д, а не текущий; выход, когда ставка ниже безубытка |
| **Дрейф β / смена режима** | пара перестаёт быть нейтральной | пересчёт β, лимиты по факторам («Корзина по факторам») |
| **Модельный** | неверная формула/допущение (например, не учтён фандинг в паритете) | сверка руками, как с реверсией QQQ |
| **Ликвидность и исполнение** | нога не исполнилась, проскальзывание | post-only, размер ≤ котировки, сначала тонкая нога |
| **Сессии TradFi** | выходные, гэпы, дивиденды QQQ | не держать открытые TradFi-связки через выходные без причины |
| **Биржевой** | ADL, сбой, изменение правил, контрагент | диверсификация площадок (Deribit и др.), не всё на одной бирже |
| **Операционный** | ошибка в объёме/стороне ноги | чек-лист перед сделкой, журнал |

## Связь с моими правилами
- «Не фиксировать убытки» хорошо сочетается с чистым арбитражем (выплата известна, можно ждать экспирацию),
  но **плохо** — со статистическим: расходящуюся пару без стопа держат только при размере от худшего MAE (так и устроены пары в дашборде).
- «Ликвидация недопустима» → главный риск арбитражника — маржа, а не цена.

## Проверь себя
1. Почему прибыльная на экспирации связка может довести до ликвидации раньше?
2. Какие из рисков таблицы не существуют для бокса на опционах, а какие остаются?
3. Почему средний фандинг за 7 дней лучше текущего для решения о кэрри?
