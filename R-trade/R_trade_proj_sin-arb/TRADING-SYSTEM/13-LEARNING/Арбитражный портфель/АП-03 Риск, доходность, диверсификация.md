# 3. Риск, доходность, диверсификация

← [АП-02 Опционы как кубики](АП-02%20Опционы%20как%20кубики.md) · [АП-00 Карта курса](АП-00%20Карта%20курса.md) · далее → [АП-04 CAPM и APT](АП-04%20CAPM%20и%20APT.md)

## Дисперсия портфеля
$$\sigma_p^2 = \sum_i\sum_j w_i w_j \sigma_{ij},\qquad \text{два актива: } \sigma_p^2 = w_1^2\sigma_1^2 + w_2^2\sigma_2^2 + 2w_1w_2\rho\,\sigma_1\sigma_2$$

## Диверсификация и её предел
$N$ активов в равных долях: $\sigma_p^2 = \frac{\bar\sigma^2}{N} + \frac{N-1}{N}\,\overline{\text{cov}}$.
При $N\to\infty$ первое слагаемое исчезает, второе — нет. Значит:
- **собственный (идиосинкратический) риск** убирается количеством;
- **систематический (общий, факторный)** — нет, его можно только **захеджировать** (короткая нога).

## Хедж-коэффициент и что остаётся после хеджа
Лонг A на $1, шорт B на $h$. Минимум дисперсии при
$$h^* = \rho\,\frac{\sigma_A}{\sigma_B} = \beta_{A\leftarrow B}$$
Остаток риска:
$$\sigma_\text{остаток} = \sigma_A\sqrt{1-\rho^2}$$
Это главная формула для пар: **хедж по бете убирает только долю $\rho^2$ дисперсии**.

| ρ | доля волатильности A, которая остаётся |
|---|---|
| 0.99 | 14% |
| 0.95 | 31% |
| 0.91 | 41% |
| 0.80 | 60% |
| 0.50 | 87% |

Пример из дашборда (снимок 07.11.2026): SOL к ETH β ≈ 0.99, ρ ≈ 0.91 → после хеджа остаётся ~41% волатильности SOL.
Поэтому в таблице «Бета к ETH» корреляция < 0.7 подсвечена как «слабый хедж».

## Почему это важно для арбитража
Арбитражный портфель по APT требует, чтобы собственный риск был **диверсифицирован** (условие 3, [АП-04 CAPM и APT](АП-04%20CAPM%20и%20APT.md)).
В книге из 3–5 крипто-активов это не выполняется → пары ETH/корзина — **статистический** арбитраж, а не чистый.
Чистый арбитраж обходит проблему иначе: ноги — **один и тот же актив** (ρ = 1 по построению: спот/фьючерс, XAUT/XAU, опционы/фьючерс).
