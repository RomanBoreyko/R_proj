# 8. Как мерить результат

← [АП-07 Риски безрисковых схем](АП-07%20Риски%20безрисковых%20схем.md) · [АП-00 Карта курса](АП-00%20Карта%20курса.md) · далее → [АП-09 Мой портфель — перестройка](АП-09%20Мой%20портфель%20—%20перестройка.md)

## Доходность на маржу, а не на номинал
Арбитраж почти не требует своих денег, но требует **маржу**. Поэтому:
$$\text{RoM} = \frac{\text{эдж, \$}}{\text{IM под связку, \$}},\qquad \text{годовая} = \text{RoM}\cdot\frac{365}{\text{дней}}$$
Сканер пока показывает % годовых **на номинал** (эдж / цена) — это нижняя оценка. Доходность на маржу — следующий шаг доработки дашборда.

## Сравнение с безрисковой ставкой
Ставка $r$ для меня — доходность USDT во Flexible Earn (видна в дашборде, блок Earn).
- Эдж конверсии/бокса/cash-and-carry **ниже** $r$ → выгоднее просто держать USDT в Earn.
- Кэрри 10% годовых при Earn 8% — реальная премия всего 2% за риск фандинга.

## Метрики книги
| Метрика | Формула / где | Цель |
|---|---|---|
| Остаточный риск $ | лучший − худший исход стресса, [Вкладка Арбитраж](../../10-DASHBOARD/Вкладка%20Арбитраж.md) | → 0 (зелёный < $150) |
| Δ$ и β-Δ | плитки [Вкладка Портфель](../../10-DASHBOARD/Вкладка%20Портфель.md) | \|·\| < $150 |
| Фандинг $/день | [Вкладка Арбитраж](../../10-DASHBOARD/Вкладка%20Арбитраж.md) | ≥ 0 |
| Θ/день | плитки | ≥ 0 или перекрыта фандингом |
| Запас маржи EQ/MM | плитки | ≥ 1.5× ([risk-rules](../../06-RISK/risk-rules.md)) |
| Доля в связках | связки / (связки + открытые ноги) по $ | растёт |
| Шарп | $(\bar r - r_f)/\sigma$ по дневному P&L | у арбитража высокий; низкий → в книге есть направленный риск |
| Худшая просадка | по журналу | ограничена и объяснима |
| Ёмкость | «объём» в сканере | эдж × объём ≥ стоимость внимания |
