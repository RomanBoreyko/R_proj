# Глоссарий и источники

← [[АП-00 Карта курса]]

## Глоссарий
| Термин | Смысл |
|---|---|
| Арбитраж | без своих денег и без риска, прибыль > 0 ([[Арбитражный портфель]]) |
| Закон одной цены | одинаковые выплаты → одинаковая цена |
| Репликация | сборка выплат инструмента из других инструментов |
| Cost of carry | стоимость держания актива до даты: ставка денег минус доход актива |
| Базис | $F - S$ (фьючерс минус спот); сходится к 0 на экспирации |
| Cash-and-carry | лонг спот + шорт фьючерса, фиксирует базис |
| Фандинг | периодический платёж между лонгами и шортами перпа |
| Кэрри | доход от удержания позиции (фандинг, базис), при захеджированной цене |
| Синтетика | лонг колла − пут того же страйка = синтетический лонг |
| Конверсия / реверсия | синтетика против фьючерса; выплата фиксирована |
| Бокс | колл-спред + пут-спред на тех же страйках; выплата $K_2 - K_1$ |
| Риск-реверсал | лонг колла K2 − пут K1 (K1 < K2); с шортом фьючерса — коридор |
| Бета (β) | чувствительность актива к фактору ([[Бета к ETH]]) |
| Систематический риск | общий для всех, не уходит диверсификацией |
| Собственный (идиосинкратический) риск | свой у актива, уходит диверсификацией |
| APT | доходность = ставка + Σ β·премия за фактор; выведена через арбитраж |
| Статистический арбитраж | β-нейтральная пара/корзина с остаточным риском |
| Остаточный риск (дашборд) | лучший − худший исход стресса ([[Стресс ETH против корзины]]) |
| Связка (дашборд) | найденная в книге арбитражная конструкция ([[Вкладка Арбитраж]]) |
| Legging risk | риск между исполнением ног связки |
| Portfolio Margin | маржа по худшему сценарию всего портфеля ([[Portfolio Margin]]) |
| Инверсный перп | расчёт в монете, размер в USD; эквивалент $Q/E$ монет |
| RoM | доходность на маржу |

## Источники
- **Andrew Lo, MIT 15.401 Finance Theory I** (плейлист «MIT corporate finance»):
  занятия 9–10 Forward and Futures, 10–12 Options, 12–14 Risk and Return / Portfolio Theory,
  15–17 CAPM and APT, 18–20 Efficient Markets. Материалы курса — MIT OpenCourseWare.
- **John C. Hull, «Options, Futures, and Other Derivatives»** — главы о ценообразовании форвардов и фьючерсов, свойствах опционов (паритет, боксы), биномиальных деревьях.
- **Stephen A. Ross (1976), «The Arbitrage Theory of Capital Asset Pricing»**, Journal of Economic Theory — исходная статья APT.
- **Bodie, Kane, Marcus, «Investments»** — главы про индексные модели, APT и многофакторные модели.
- **Shleifer, Vishny (1997), «The Limits of Arbitrage»**, Journal of Finance — почему арбитраж ограничен капиталом.
- **Справочный центр Bybit** — комиссии, фандинг, Portfolio Margin, цена поставки опционов и фьючерсов (правила меняются — сверять).
- Свои: [[DASHBOARD]] (техдока дашборда), [[D1-арбитраж-под-прикрытием-опционов]], [[basis-desk-родословная]], [[spread-screening-card]].
