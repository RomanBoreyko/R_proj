# 6. Маржа Portfolio Margin

← [ОС-05 Опционы SOXL](ОС-05%20Опционы%20SOXL.md) · дальше [ОС-07 Два слоя скальпа](ОС-07%20Два%20слоя%20скальпа.md)
## 1. Как Bybit считает
- **MM** = худший сценарий по сетке «ход цены × шок IV» **по каждой базовой монете отдельно** плюс надбавки. **IM ≈ 1.2 × MM.**
- Монеты между собой не зачитываются. SOXL и SOXS — разные монеты, поэтому маржа пары = **сумма** худших.
  - 16.11: Bybit берёт ~$135, а худший случай с учётом зеркала ≈ −$37.
- **Шок IV — в процентах от IV.** Калибровка по ноге 4DEC-54P ×5: пересчёт Bybit совпадает с Блэком–Шоулзом при сдвиге IV ≈ +56% / −49% от текущей.
- У купленных опционов худший сценарий — **IV вниз при той же цене**. 16.11 он давал почти всю маржу SOXL (без хода цены −$36 из −$37).

## 2. Правила IM
- **≥ 100%** — проходят только ордера, уменьшающие IM. **50%** — рабочий потолок оператора. **40%** — жёлтый, новых ног не добавлять.
- **Запас до ликвидации** = эквити − MM.

## 3. Ловушки (все случились 15–16.11)
| Что сделал | Что стало с маржой | Почему |
|---|---|---|
| Хедж другой монетой (SOXS против SOXL; опцион одной монеты против перпа другой) | выросла | монеты не зачитываются |
| Выкуп проданных путов «чтобы освободить маржу» | выросла | проданные гасили сценарий «IV вниз» купленных |
| Закрытие большой книги по одной ноге | худший рос на каждом шаге | сначала уходила нога, которая гасила другую |
| Закрытие **пропорциональными срезами** всех ног | худший падал линейно | все сценарии масштабируются вместе |

## 4. «Что если» — до сделки
- Деск показывает таблицу «Маржа спреда»: сценарии по монетам и их сочетание.
- Добавить ногу той же монеты — пересчитать сценарии (прибавить P&L ноги в каждом узле). Так считалась оценка «путы вместо SOXS» в [ОС-05](ОС-05%20Опционы%20SOXL.md).
- Ногу другой монеты Bybit прибавит целиком.

## Проверь себя
1. Худший по SOXL −$60, по SOXS −$40, с учётом зеркала −$25. Какую MM возьмёт Bybit (без надбавок)?
2. Почему выкуп проданного пута может *увеличить* MM?

<details><summary>Ответы</summary>

1. **$100** — сумму по монетам. Зеркало Bybit не видит.
2. Если книга длинная по веге, худший сценарий — «IV вниз». Проданный пут в нём зарабатывает и гасит убыток. Без него худший глубже.
</details>
