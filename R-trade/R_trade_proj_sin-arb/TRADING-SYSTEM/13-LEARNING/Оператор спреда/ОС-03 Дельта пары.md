# 3. Дельта пары

← [ОС-02 Перпы Bybit на ETF](ОС-02%20Перпы%20Bybit%20на%20ETF.md) · дальше [ОС-04 Гамма и тета пары](ОС-04%20Гамма%20и%20тета%20пары.md)

## 1. Дельта внутри дня — по зеркалу
Пусть $L_0, S_0$ — цены на прошлом закрытии США, $L$ — текущая цена SOXL. По якорю $S = S_0(2 - L/L_0)$. Чувствительность книги к ходу SOXL на 1 (в $ SOXL-эквивалента):
$$\Delta_\$^{день} = \Delta_L\cdot L \;-\; \Delta_S\cdot S_0\cdot\frac{L}{L_0}$$
- $\Delta_L$, $\Delta_S$ — в штуках: перп + Σ дельт опционов (греки Bybit по позиции) + спот;
- если $L$ рядом с $L_0$, это почти $\Delta_L L - \Delta_S S$: **SOXS гасит SOXL доллар в доллар**, без β.

## 2. Дельта после закрытия
На закрытии база переклеивается ($L_0 \to L$, $S_0 \to S$):
$$\Delta_\$^{после} = \Delta_L\cdot L - \Delta_S\cdot S$$
**Скачок дельты на закрытии** = $\Delta_S\,(S_0 L/L_0 - S)$. При лонг-лонге и ходе SOXL за день на $r$ это ≈ $2N_S r$: после роста книга становится лонгом, после падения — шортом. Это и есть «гамма» пары: она приходит рывком раз в день, а не непрерывно.

## 3. β из регрессии — для многодневного взгляда
- β SOXS/SOXL по дневкам за 120 дней ≈ −0.94. Это **среднее с учётом переклеек** (см. [ОС-01](ОС-01%20Плечевые%20ETF%20и%20якорь%20дня.md)).
- Внутри дня хеджировать по β −0.94 = недохеджировать SOXS на ~6%. На $330 номинала это ~$20 ложной дельты.
- β по часам за 3 дня (−0.87 на 16.11) шумит сильнее: в окно попадают переклейки на закрытиях.

> **Связь с Ло — хедж-коэффициент.** $h^* = \rho\,\sigma_A/\sigma_B = \beta$ — оптимальный хедж, когда связь статистическая. Если связь **контрактная** (мандат фонда), хедж задаёт контракт: внутри дня h = −1 на базе закрытия. Статистика нужна только там, где контракта нет: между днями.

Подробно, с примерами в долларах и распадом: [ОС-13 Бета и зеркало](ОС-13%20Бета%20и%20зеркало.md).

## 4. Пример (16.11, ~13:00)
SOXL: перп +6.31, опционы −0.20 → **6.11** × 52.39 = $320. SOXS: перп **5.97** × 56.12 = $335.
- по зеркалу (≈ после закрытия): 320 − 335 = **−$15**;
- по β −0.94 (как деск считал утром): 320 − 0.942 × 335 = **+$5**.
Разница — 20 долларов и знак. Деск переведён на зеркало (16.11).

## 5. Опционы в дельте
Дельту опционов берём у Bybit (по mark IV). Она «плавает» с ценой и IV — это гамма и ванна. Порог хеджа ±$40 на деске учитывает её уже.

## Проверь себя
1. Закрытие: SOXL 50, SOXS 60. Сейчас SOXL 52. Лонг 6 SOXL и 5 SOXS. Дельта внутри дня? После закрытия, если цены не изменятся?
2. Почему нельзя хеджировать по β −0.94 внутри дня?

<details><summary>Ответы</summary>

1. По якорю SOXS = 60·(2 − 52/50) = 57.6. Внутри дня: 6·52 − 5·60·52/50 = 312 − 312 = **$0**. После закрытия: 6·52 − 5·57.6 = 312 − 288 = **+$24** — скачок +$24 к лонгу (рос SOXL).
2. Внутри дня связь — мандат с коэффициентом −1. Хедж −0.94 оставляет 6% SOXS непокрытыми.
</details>
