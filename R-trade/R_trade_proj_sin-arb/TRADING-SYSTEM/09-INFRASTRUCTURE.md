# Стек оператора спреда

← [00-INDEX](00-INDEX.md)

| Роль | Приложение | Что делает |
|---|---|---|
| Биржа | **Bybit** (UTA, Portfolio Margin) | перпы `SOXLUSDT` / `SOXSUSDT`, опционы SOXL |
| Исполнение | **MetaScalp** | скальп-стакан, лимитки. «Позицию» считает по журналу своих сделок — баланс сверять по деску |
| Графики | **TradingView** (приложение, подписка) | SOXL и SOXS линиями, спред в подвале |
| Цифры и риск | **Деск** `http://localhost:8899/` | Δ до и после закрытия, гамма, тета, маржа, коридор, учёт. Техдока: [DESK.md](scripts/portfolio/DESK.md) |
| Знания и журнал | **Obsidian** (этот волт) + git (GitHub `R_proj`) | спецификация, курс, чек-лист, журнал |
| Помощник | **Claude Code** | деск, расчёты, документация. API только на чтение |
| Секреты | KeePassXC | ключ API Bybit (только чтение) — локально в `C:\Users\DoOs\.bybit\credentials.json`, в git не попадает |

Прежняя схема стека — в [архиве](99-АРХИВ/09-INFRASTRUCTURE%20(архив).md).
