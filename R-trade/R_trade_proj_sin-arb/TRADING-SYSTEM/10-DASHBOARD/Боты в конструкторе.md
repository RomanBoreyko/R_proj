# Боты Bybit в конструкторе позиции — как добавить нового

Хаб: [Вкладка Деск](Вкладка%20Деск.md) · Техдока: [DESK.md](../scripts/portfolio/DESK.md) (раздел «Боты»)

Во вкладке «Деск → Конструктор позиции» под плитками счёта — **строка плиток на каждого бота**. Данные идут из API Bybit по ключу только для чтения раз в 5 с. Деск ботами не управляет: доливка, остановка и правка — руками на Bybit.

## Добавить бота за 3 шага

1. **Скопируй Bot ID.** Bybit → My Bots → бот → Details. Под «Bot ID» нажми значок копирования (например, `123456789012345678`).
2. **Впиши ID в файл** `C:\Users\DoOs\.bybit\bots.json` — это та же папка, где лежат ключи API. В репозиторий файл не попадает. Добавь строку в список `bots`:

   ```json
   {
     "bots": [
       {"id": "123456789012345678", "type": "grid", "name": "SOXL лонг-сетка 44–54"},
       {"id": "<новый Bot ID>", "type": "martingale", "name": "SOXL мартингейл x2"}
     ],
     "topup_pct": 15,
     "warn_pct": 25
   }
   ```

   - `type`:
     - `grid` — фьючерсная сетка (Futures Grid): лонг, шорт или нейтральная;
     - `martingale` — фьючерсный мартингейл (Futures Martingale).
   - `name` — любая подпись для плитки.
   - Строки разделяются запятыми, после последней запятой нет. Кавычки только прямые `"`.
3. **Обнови страницу** деска. Перезапуск сервера не нужен: файл читается на каждом обновлении.

**Бот остановлен** — удали его строку. Пока строка есть, плитка покажет «бот не работает» и причину закрытия (стоп, ликвидация, вручную).

**Ошибка «нет данных: …»** — неверный ID или `type`. Мартингейл с `type: grid` не найдётся, и наоборот.

**Не проверено:** спотовые сетки, DCA и Combo деск не читает. Мартингейл подключён по документации Bybit, на живом боте ещё не проверялся.

## Что показывает строка бота

| Плитка | Что значит |
|---|---|
| **Сигналы** (рамка) | Худший сигнал первым: зелёный — норма, жёлтый — внимание, красный — действовать |
| Цена / диапазон | Цена маркировки, границы сетки, внутри / ВЫШЕ / НИЖЕ |
| Засажен | Сколько сетки уже набрано в позицию. Лонг-сетка: (верх − цена) / (верх − низ). Шорт — зеркально. Нейтральная — от цены входа до ближнего края. У мартингейла — использованные доборы |
| Позиция | Контракты и $ сейчас; «на краю» — оценка полной позиции |
| Ликвидация сейчас | От Bybit, по текущей позиции, и расстояние до неё в % |
| Ликвидация на краю | Оценка, если цена дойдёт до края диапазона и сетка наберётся целиком. Это худшая ликвидация бота без доливки |
| Доливка $… | Куда уйдут обе ликвидации, если долить весь свободный USDT с Funding |
| P&L | Итог, прибыль сетки, число сделок (всего и за 24 ч) |
| Маржа бота | Эквити бота: под позицией, под ордерами, свободно |

Под строкой — **Δ книги с ботами**: дельта опционов и перпов книги плюс позиции ботов (SOXS — по зеркалу). В таблицу ног и P&L-кривую боты не входят.

## Сигналы и что делать

| Сигнал | Когда | Действие (по твоим правилам: без стопов) |
|---|---|---|
| в норме | цена в диапазоне, ликвидация дальше 25% | ничего |
| засажен на ≥ 80% | цена у нижнего края лонг-сетки (у верхнего — шорт-сетки) | приготовить доливку, посмотреть плитку «Ликвидация на краю» |
| «если цена дойдёт до края … останется ~X%» | ликвидация на краю ближе 25% к краю | заранее решить, хватит ли резерва |
| цена НИЖЕ / ВЫШЕ диапазона | сетка не торгует | засажен на 100% — ждать возврата или доливать. Позиция 0 — бот просто стоит |
| риск ликвидации | до ликвидации < 25% (`warn_pct`) | следить, держать резерв на Funding |
| **ПОРА ДОЛИВАТЬ** | до ликвидации < 15% (`topup_pct`) | Bybit → бот → **Invest More**, сумма из резерва на Funding. Плитка «Доливка» заранее показывает, куда уйдёт ликвидация |
| бот не работает | бот закрыт (стоп, ликвидация, вручную) | удалить строку из bots.json |

Пороги меняются в `bots.json`: `topup_pct` и `warn_pct` — в процентах от цены.

## Резерв доливки и хедж

- **Резерв** — свободные USDT на **Funding**. Деск читает их сам. С Funding доливка не трогает маржу основного счёта.
- **Переливание** — прибыль хеджа (например, подорожавших путов) продаёшь на основном счёте. Потом переводишь: единый счёт → Funding → Invest More в боте. Подробно — в чате 18.11.
- **Пример: лонг-сетка 44–54, x3, вложение $30.** Ликвидация на краю ≈ 32.3. С доливкой $20 она уходит ≈ на 22.5. Купленные путы со страйком у нижнего края начинают платить как раз там, где сетка засажена целиком.

## Оговорки

- «Ликвидация на краю» — оценка сверху: позиция на краю принимается как вложение × плечо / цена края, у Bybit она бывает меньше. Bybit при создании этого бота показывал 35.07, деск — около 32.
- Прибыль сетки и комиссии — данные Bybit. У ботов свои комиссии: на 18.11 maker 0.02%, taker 0.055%, а не 0% maker, как в ручной торговле SOXLUSDT.
