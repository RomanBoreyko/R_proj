# Онбординг: чем Роман занимается сейчас (трейдинг)

> Репо публичное: здесь нет ключей и сумм счёта. Живые цифры — только из деска или API.

## 1. Кто и как
- **Роман (Ро)** торгует руками на **Bybit** (единый торговый аккаунт, **Portfolio Margin**) и **MEXC**. Исполнение — MetaScalp и приложение Bybit, графики — приложение TradingView (с подпиской).
- Пишет по-русски или по-украински, коротко, часто командами: «статус», «расклад», «нейтралим», «режем плечо», «комить».
- Решения принимает сам. Нейронки дают **анализ, цифры, варианты**. Персональных инвестсоветов не давать, ордера **не ставить**: API-ключи только на чтение.

## 2. Текущий фокус (с 16.11.2026)
**Спред SOXL / SOXS как гамма-позиция.**
- Лонг обоих перпов Bybit (SOXLUSDT + SOXSUSDT). **Внутри дня SOXS — точное зеркало SOXL от прошлого закрытия США** (мандат фондов; σ отклонения 0.10%): пара линейна, гаммы не даёт. Через закрытие база переклеивается, и дельта прыгает: пара — ставка на тренд между днями.
- β ≈ −0.94 из регрессии по дневкам годится только для многодневного взгляда. Дельту деск считает по зеркалу (с 16.11).
- Гамму для скальпа дают только опционы SOXL (около денег, экспирация 4DEC).
- Доход — **гамма-скальп перпом SOXLUSDT** по коридору дельты. Расход — тета опционов и распад пары ETF.
- **План:** перенести риск спреда в опционы (путы SOXL вместо лонга SOXS), чтобы снизить маржу: PM не зачитывает SOXS против SOXL. Сравнение — курс ОС-05, раздел 3.

**Закрыто или отложено:**
- **ETH** («трёхногий каркас» с 10.11: проданные путы + шорт инверса + коллы) **закрыт целиком 16.11**: IM дошёл до ~98%. На деске ETH скрыт (`DKETH=0`). Продажу далёких путов ETH Роман хочет вести **в другом аккаунте**.
- **Золото** (колл XAUT + ошибочный хедж XAUUSDT) закрыто 16.11.
- **Шиткоины** — после ликвидации INIT 15.11. План — рой мелких ботов MEXC + Bybit в отдельных счетах: `R-trade/…/TRADING-SYSTEM/03-STRATEGIES/S1-рой-ботов-шиткоины.md`. Пока не начат.

## 3. Правила риска (текущие, из практики 15–16.11)
- **IM ≤ 50%.** Выше — никаких новых ног, только сокращение. Деск подсвечивает: ≥ 40% жёлтым, ≥ 50% красным.
- **Тета портфеля:** предупреждение, если хуже −$10 в сутки.
- **Хеджировать той же монетой.** PM считает каждую базовую монету отдельно: SOXS против SOXL, XAU против XAUT, BTC против ETH маржу **удваивают**.
- **Выкуп проданных опционов может увеличить маржу**, если книга длинная по веге.
- **Закрывать большую книгу при высоком IM** — пропорциональными срезами всех ног, а не по одной.
- «Не фиксировать убытки» — правило Романа. Если вариант означает фиксацию убытка, прямо говорить, сколько фиксируется.
- Полные правила: `R-trade/…/TRADING-SYSTEM/06-RISK/risk-rules.md`.

**Повторяющиеся ошибки** — помогать ловить:
- перепутанная сторона или инструмент: ETHUSD **лонг** вместо шорта, XAUUSDT вместо XAUTUSDT, закрыта не та нога;
- плечо через разномонетные хеджи;
- позиция в MetaScalp ≠ баланс Bybit: MetaScalp считает «позицию» по своему журналу сделок и не видит займов.

## 5. Что полезнее всего делать для Романа
1. **«Статус»:** эквити, IM/MM, запас до ликвидации, Δ SOX, Γ книги, тета, безубыточный ход против RV — из деска или API, только проверенные цифры.
2. **Перед сделкой:** что будет с маржой, «что если» по сценариям PM. Проверить сторону и инструмент.
3. **После сделки:** сверить позиции в API с тем, что Роман хотел сделать.
4. **Гамма-скальп:** уровни коридора, окупает ли скальп тету (closed PnL против теты), куда выгоднее положить гамму (Γ на $1 теты по экспирациям).

## 6. Безопасность и git (кратко; полностью — корневой `CLAUDE.md`)
- Ключи Bybit/MEXC — только чтение. Не печатать, не логировать, не коммитить (`C:\Users\DoOs\.bybit\credentials.json` — только локально).
- Без ордеров, переводов и изменения настроек аккаунта.
- Пакеты не ставить и задачи в Планировщике не создавать без спроса.
- Git: коммит **только по слову «комить»**.
  - Перед `git add` — `python -I tools/git_autosave.py --dry-run`.
  - `git add` только явными путями, потом `git pull --rebase --autostash`. Без force-push.
  - Префиксы коммитов: `[R-trade]` / `[R_tail]` / `[общее]`.
- **Не коммитить реальные суммы счёта.** История ликвидаций в `_coord/inbox/…история-ликвидаций.md` лежит неотслеживаемой по решению Романа.
- `book_dashboard.py` правят и спредер, и Gemini: перед правкой смотреть `_coord/CHAT.md` и время изменения файла. id `dk*` и функции деска (`dtick`, `renderDesk`, `renderTiles`, `dlive`, `dkGam`) не трогать без согласования.
