# 🌀 BR_zalgo - Demon Zalgo

Автономный демон искажения текста, который работает в фоне и активируется CAPS LOCK'ом.

## 🎯 Описание

Demon Zalgo - это локальное приложение, которое:
- **Работает в фоне** (отдельный процесс без окна)
- **Запускается двойным кликом** (например, `zalgo_demon.exe` на рабочем столе)
- **Отслеживает CAPS LOCK** и активирует режим искажения
- **Перехватывает нажатия клавиш** и подменяет ввод на залго-текст
- **Ведёт журнал** всех преобразований

## 🏗️ Архитектура

1. **Слушает состояние CAPS LOCK** — когда включён, активируется фильтр
2. **Перехватывает клавиши** (только буквенные, пробел и пунктуацию)
3. **Подменяет их на залго-версию** (искажённые символы)
4. **Вводит результат обратно** (через симуляцию нажатий)
5. **Работает тихо в фоне**, можно без консоли

## 🚀 Быстрый старт

### Вариант 1: Установка и запуск из исходников

1. **Установите Python** (если не установлен)
2. **Запустите установку:**
   ```bash
   install.bat
   ```

### Вариант 2: Сборка исполняемого файла

1. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Соберите exe файл:**
   ```bash
   build.bat
   ```

3. **Скопируйте** `dist/zalgo_demon.exe` на рабочий стол

## 🎮 Использование

### Базовая версия (`zalgo_demon.py`)
- **Запуск:** `python zalgo_demon.py`
- **Переключение режима:** CAPS LOCK
- **Остановка:** Ctrl+C

### Расширенная версия (`zalgo_demon_advanced.py`)
- **Запуск:** `python zalgo_demon_advanced.py`
- **Переключение режима:** CAPS LOCK или Ctrl+Shift+Z
- **Статистика:** Ctrl+Shift+S
- **Управление:** Правый клик по иконке в системном трее

## ⚙️ Конфигурация

### Основные настройки (`zalgo_config.json`)
```json
{
  "intensity_min": 1,           // Минимальная интенсивность искажения
  "intensity_max": 3,           // Максимальная интенсивность искажения
  "log_file": "zalgo_log.txt",  // Файл логов
  "sound_enabled": true,        // Звуковые уведомления
  "auto_backspace": true        // Автоматическое удаление оригинала
}
```

### Расширенные настройки (`zalgo_config_advanced.json`)
```json
{
  "hotkey_toggle": "ctrl+shift+z",  // Горячая клавиша переключения
  "hotkey_stats": "ctrl+shift+s",   // Горячая клавиша статистики
  "show_notifications": true,       // Уведомления в трее
  "auto_save_stats": true,          // Автосохранение статистики
  "stats_file": "zalgo_stats.json"  // Файл статистики
}
```

## 🐛 Устранение неполадок

### Python не найден
- Установите Python с [python.org](https://python.org)
- При установке отметьте "Add Python to PATH"

### Ошибки зависимостей
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### Демон не реагирует на CAPS LOCK
- Проверьте, что Python запущен с правами пользователя
- Убедитесь, что другие программы не блокируют клавиатуру
