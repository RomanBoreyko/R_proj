# 🌀 Demon Zalgo - Быстрый старт

## 🚀 Запуск (3 способа)

### 1️⃣ **Готовый exe файл** (рекомендуется)
```bash
# Скопируйте на рабочий стол и запустите двойным кликом
dist/zalgo_demon.exe
```

### 2️⃣ **Из исходников**
```bash
# Установка и запуск одной командой
install.bat
```

### 3️⃣ **Ручная установка**
```bash
pip install -r requirements.txt
python zalgo_demon.py
```

## 🎮 Управление

| Действие | Команда |
|----------|---------|
| **Включить режим залго** | Нажмите **CAPS LOCK** |
| **Выключить режим залго** | Нажмите **CAPS LOCK** снова |
| **Остановить демон** | **Ctrl+C** в консоли |

## ✨ Что происходит

1. **Запускаете демон** → он уходит в фон
2. **Включаете CAPS LOCK** → слышите звук активации 🩸
3. **Печатаете текст** → буквы превращаются в залго-символы
4. **Выключаете CAPS LOCK** → всё возвращается в норму 💀

## 📊 Примеры

**Обычный текст:** `Привет мир!`
**Залго текст:** `П̅̿р̑̐и̋̾в̎̄е̅̿т̎̄ ̑̐м̋̾и̅̿р̎̄!̋̾`

## 🔧 Расширенная версия

Для большего функционала (трей, горячие клавиши, статистика):
```bash
python zalgo_demon_advanced.py
```

**Горячие клавиши Advanced версии:**
- `Ctrl+Shift+Z` - переключение режима
- `Ctrl+Shift+S` - статистика
- Правый клик по иконке в трее - меню

## 📁 Файлы

- **Логи:** `zalgo_log.txt`
- **Конфигурация:** `zalgo_config.json`
- **Статистика:** `zalgo_stats.json` (Advanced версия)

## 🛑 Остановка

- **Консольная версия:** `Ctrl+C`
- **Exe версия:** Закройте через диспетчер задач
- **Advanced версия:** Правый клик по иконке в трее → Exit
