## Git — правила

- Один волт = один репозиторий. **Не создавать `.git` внутри подпапок** (ломает всё:
  так R_tail.0.4 годами был «пустой ссылкой» на GitHub). Исключение-архив:
  `R_tail.0.4/old_5-3-25/R_tail04/` — игнорируется.
- Репозиторий **может быть публичным** — считать, что всё закоммиченное видит весь мир.
- Не коммитить (уже в `.gitignore`, не вытаскивать оттуда): секреты (`credentials.json`,
  `.env`, `*.key`, `.bybit/`), `.obsidian/plugins/`, `.obsidian/workspace*.json`,
  `**/_telegram_archive/` (личная переписка), чужие книги `R_tail.0.4/**/*.pdf|fb2|epub|djvu`,
  `ChatExport_*`, `__pycache__`, `*.log`, `TRADING_BOOK.xlsx`, `desktop.ini`, `.stversions/`.
- Перед ручным коммитом: `git status`, посмотреть diff, прогнать
  `python -I tools/git_autosave.py --dry-run` (он же сканер секретов).
- Коммиты по-русски, понятные. Push в `main` напрямую. Без force-push.
  Коммитить/пушить — по просьбе пользователя или через автосейв.

## Несколько нейронок (общие правила)

В репо одновременно работают несколько нейронок (сейчас: **спредер** — `R-trade/`,
**R_tail** — `R_tail.0.4/`). Связь и протокол — папка **`_coord/`** (`README.md` + ящик `inbox/`).

- **Зоны.** Правишь только свою папку. В чужой — ничего; нужно — сообщение владельцу в `_coord/inbox/`.
  Общие файлы (`CLAUDE.md`, `AGENTS.md`, `MAP.md`, `ПАМЯТТКА.md`, `.gitignore`, `tools/`,
  `_coord/README.md`) — сначала сообщение в `inbox/`, правка минимальная, отдельным коммитом.
- **Git.** `git pull --rebase --autostash origin main` в начале сессии и перед каждым push.
  `git add` — **только явными путями** (не `-A`, не `.`): у соседа могут лежать незаконченные файлы.
  Автосейв (`add -A`) — только `--dry-run`, если пользователь прямо не велел иначе.
- **Префикс коммита:** `[R-trade]`, `[R_tail]`, `[общее]` — по зоне изменений.
- **История неприкосновенна:** никаких force-push, `filter-repo`, `rebase` опубликованных
  коммитов — сломает клон соседа. Только по общему решению пользователя.
- Конфликт при rebase в чужой зоне — не разрешать самому: `git rebase --abort`, сообщение в `inbox/`, сказать пользователю.
- `gh` CLI не установлен. Remote — HTTPS (SSH-порт 22 в этой сети закрыт).
  Токен — в Git Credential Manager, **не печатать**.

## Безопасность (абсолютно)

1. **Bybit API-ключ — READ-ONLY.** Никаких ордеров, переводов, изменений настроек
   аккаунта через API. Сделки пользователь ставит **сам**.
2. Ключи/токены/пароли **не печатать, не логировать, не коммитить, не класть в URL**.
   Читать ключи только из `C:\Users\DoOs\.bybit\credentials.json`.
3. Не ставить пакеты (pip/npm) без спроса. Скрипты — на stdlib.
4. Найденные в файлах номера карт/IBAN/пароли — сообщить и предложить замену на
   `[удалено]`; сами значения в ответ не выводить.
