# Процедура вскрытия Чёрного Ящика

1. Постановка задачи — заказчик ЗМД.
2. Испытательная среда — [[Саркоза]] (цифровой двойник, песочница).
3. Декомпозиция на функции-роли: Оператор, Курьер, Режиссёр, Ходок, Инквизитор.
4. Зондирование — стук Симург (метод Эшби, идентификация систем).
5. Внедрение агента — [[Саара]] на болоте (открытый порт).
6. Рукопожатие — пентаграмма [[Бледный|Бледного]].
7. Эскалация — Курьер, Режиссёр по каналу.
8. Захват управления — аватар, [[Шкатулка Рыжего]].
9. Приёмка — Инквизиция зачищает следы.

**Методы:** Эшби, идентификация систем, тестирование чёрного ящика, фаззинг, L* (обучение автоматов), побочные каналы, суррогатные модели / цифровой двойник, песочница.
**Ошибки эмуляции:** пробелы в данных (заглушки), подмена средним (одинаковые коты, жёны), утечка провидения (эхо раньше хлопка).
**Оптимизация:** LOD, отсечение невидимого, ленивые вычисления, инстансинг, кэш, сон объектов, сжатие → отрисовка из памяти.
**Точки отказа:** Рыжий, Бледный, Оператор.
