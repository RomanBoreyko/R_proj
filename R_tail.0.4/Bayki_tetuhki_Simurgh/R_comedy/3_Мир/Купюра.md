# Купюра

**Не баг — технология.**

- «Купюры — области пространства-времени, которые по решению [[Институт государственной инквизиции|ИГИ]] помещены на информационный карантин» (Вира). Закрыты политикой безопасности СТДМ.
- Производятся и выпускаются **по патентам бюро Лиличей**.
- Вид: беспросветно чёрное, не отражает свет (письмо Виры, внутренность [[Маска Крысиного пророка|маски]], нити в резьбе Орфа, чёрные страницы Ральфа).
- Конкретная купюра из Щхер → декану Люричеву, с письмом мозгоправа.

## Архитектура
1. Носитель — Культура Медкорпуса (почва [[Бассейн]]а).
2. Права — Линия Администрации.
3. Чертёж — патент Лиличей.
4. Исполнитель — Администрация из Чёрного Ящика.
5. Железо — песочница СТДМ (эмуляция Администрации).

Связь: [[Склейки]] (то же снизу, глазами жителей).
