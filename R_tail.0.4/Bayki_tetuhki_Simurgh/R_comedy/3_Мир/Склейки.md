# Склейки

Дыры-баги в симуляции. Название от монтажной склейки: начало действия склеено с концом.

## Правила
1. **Пропуск процесса** — хочешь сделать, результат уже есть, действия не было.
2. **Подшивка памяти** — вклеивается гладкое воспоминание о действии.
3. **Тьма на месте** — не темнота, а непрорисованность.
4. **Ключ — геометрия** — шар, золотое сечение, Многогранник ломают сетку.
5. **Тело не входит** — рука уходит и возвращается целой. Тело = интерфейс.
6. **Цена** — каждое использование = ещё одно ложное воспоминание.
7. **Почтовый ящик** — всё оставленное видят с той стороны (канал Симург).
