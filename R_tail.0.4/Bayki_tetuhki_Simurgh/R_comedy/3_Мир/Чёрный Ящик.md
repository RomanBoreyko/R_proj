# Чёрный Ящик

- Получен СТДМ от ЗМД (Зион). Симург вскрывает.
- **[[Изнанка]] = содержимое ящика**: Дом, Лес, болото, Сид.
- Симург стучит (тук, пауза, тук) — зондирование; первый ответ изнутри — пентаграмма Бледного.
- Форма: шкатулка-головоломка, складывается в мини-Многогранник.
- [[Шкатулка Рыжего]] — аватар (носитель) для ящика.
- На Пике Зион перепоручает ящик Рыжему.
- догадка: открывается только у того, кто перестал хотеть то, что внутри.
