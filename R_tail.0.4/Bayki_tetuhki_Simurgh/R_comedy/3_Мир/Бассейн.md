# Бассейн

- В подвалах **Серого Дома**.
- Почва + Культура Медкорпуса + Линия Администрации + Покой под лицензией [[Могильник]]а.
- Построен агентом [[Омут]]а. Реставрирован [[Червь|Червём]] (нанят Бри по контракту Матушки Анны). Под ним купюра.
- **Инкубатор:** кафель из сцены рождения Рыжего = Бассейн. Рыжий и Крыса вылупились здесь.
- [[Медкорпус]] забирает спящих = собирает урожай своей Культуры.
- Старое: бассейн для электрожелез (Матушка Анна).
