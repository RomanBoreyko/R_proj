## Руководство для оператора системы управления Культурой Администрации штамма parum magister, для проведения настольных игр.

### 1. Первый запуск СУКА:

Перед первым включением системы СУК подготовьте главные модули:
- интерфейс Оператора (браслет и указатель), 
- Усы сенсоры, 
- навигационный щуп,
- Питомник.

Дождитесь пока Паук, проверит модули.

Усами соедените Питомник с браслетом, указателем, щупом. Браслет соедените с указателем, щупом. Оставшиеся Усы из комплекта, подключите к контактам Альфа, Бета, Дельта, оставив другие концы Усов свободными. Проверьте целостность корпуса Питомника, места соединения с Усами на всех модулях. Система требует проверки всех входных интерфейсов в соответствии с протоколом Медкорпуса.см.Дополнение1.

#### А) Подготовка Оператора и устройств:

Наденьте браслет. Усы от контактов Альфа, Бета, Гамма, приложите к нервным узлам локтя, расположение которых указал ваш Паук. Зафиксируйте их не живым, не органическим средством. 

Установите Питомник на ровную поверхность. Не допускайте выхода температуры внутри корпуса Питомника за пределы диапазона от -5 до +80 градусов по цельсию. Иначе Культура может заболеть, уйти в режим гибернации, впасть в спячку.

Откройте копус Питомника. Убедитесь, что биосреда (жидкий гель) в "кухне" залита до метки «МИН». Вставте ключ рычаг в паз с символом ████ на корпусе Питомника. Прокрутите завод механической батареи. Культура мигнет люминисцентными водорослями. Ускорит метаболизацию биосреды, привлечение запасной биомассы, подаст заряд на щуп, браслет, указатель.

Дождитесь пока Усы проникнут под кожу и возьмутся за ваши узлы. После этого, результаты включения, вернутся на нервные узлы Оператора, на электрохимическом диалекте.

Отправьте на браслет команду для синтезации меметика  ██████:  

```
G90             ; Абсолютное позиционирование
M100 P1         ; Включить интерфейс браслета
M101 M3         ; Прием электрохимии через Усы
G04 P2000       ; Задержка 2 сек для стабилизации интерфейса
M150 R255 G255 B255 ; Активация меметика ████████████ (визуальный сигнал белым светом, Визуальная индикация активации)
G04 P500        ; Подождать 0.5 сек
M102            ; Начать синтезацию меметика
M103 S1         ; Подтвердить успешный запуск синтезации
M30             ; Конец программы

```

█████ дополнит ваш интерфейс восприятия, трехмерной средой названой Бардо. 

Интерфейс Бардо, эмулируется на вычислительных средствах Культур. Он одинаковый, для всех, везде и не зависимо от используемой Культуры или внесенных в нее модификаций.

Электрохимическая информация, которую принимает от вас браслет, будет передаватся через фотонно-цифровой интерфейс Бардо, к исполняющей Культуре.

Метаболизм человека, ликвидирует █████ за восемь секунд. Эффекты (согласованная галлюцинация интерфейса Бардо) должна сохранятся дольше восьми секунд после метаболизации █████. Для стабильной трансляции интерфейса Бардо, рекоммендуется использовать цикл с четырех или шести секундной задержкой.

Пример:
```
G90 M100 P1 M101 M3 G04 P2000

WH [ΣA AND ΣD AND ΣS AND ΣN AND ΣG] DO1
    M150 R255 G255 B255 G04 P500
    M102                     ; Начать синтезацию меметика █████
    M103 S1 G04 P4000
END1

M30
```
Здесь `ΣA` `ΣD` `ΣS` `ΣN` `ΣG` — электрохимия, воспринимаемая браслетом в области контакта Альфа. Их значения интерпретируются системой как команды для интерфейса Бардо.

Проверьте синхронизацию указателя с Культурой через Бардо.

Дождитесь пока СУКА проведет самодиагностику и выведет результат сигналами в Бардо или на нервные узлы, на электрохимическом диалекте.

#### Б) Настройка щупа.

Коснитесь щупом рабочей поверхности. Рекоммендуется использовать стол. В Бардо и в узлах отразятся координаты точки касания. Выполните процедуру калибровки щупа. см. Дополнение 2.

Обмеряте рабочую поверхность по осям XYZ. Привяжите нули для работы с рабочей поверхностью. Установите нули для визиток игроков, для колоды карточек событий, для фишек игроков, для фишек и карточек ресурсов. 

Подождите пока рабочая поверхность покроется Культурой, а Культура изобразит игровую карту. Пока картинки отобразятся на остальном игральном инвентаре.

По завершении процедуры, вернутся результаты в Бардо и на узлы Оператора.

#### В) Настройка указателя. 

Щупом, установите нули указателя, отрегулируйте его чувствительность, синхронизируйте с навыками обмена данными через узлы Оператора. см. Дополнение 3.

Результаты будут выводится на узлы Оператора.
