# Бледный

**Дополнение к карточке** (если есть — слить).

## Кто
- Повзрослевший **Слепой** из Дома. Маленький Слепой с другого Витка — его прежняя версия.
- Ходок, Прыгун, перекидыш (волк на стороне Леса). Драка с Чёрным в Самую Длинную. С Ральфом: «можно только слушать». Звал Сфинкса на Изнанку — тот отказался.
- Ушёл на [[Изнанка|Изнанку]] после Дома.
- Зрачки светятся зелёным = **[[Симург]] смотрит его глазами**.
- Пара — [[Крыса]].

## Под капотом: Киасиды
Механика бладлайна Киасидов (Мир Тьмы) — двигатель, Бледный — фронтенд: кровь по вене, связь с Чернобогом → **Чернолес** (решение по Темнолес/Чернолес), гримуар (glamour/grammar/grimoire → Кодекс), непереносимость железа.

## [[Саара]]
В Самую Длинную через коридоры ушёл в Лес → болото → встретил Саару. Поймал в пентаграмму. Рукопожатие → пинг ушёл Симург, она уцепилась.
догадка: пентаграмма = запрос в СТДМ, 5 печатей (Культура, Линия, Корона, Покой, Память), в центре зубчатка.

## Гипотеза симуляции
- Старт: **тело = интерфейс** (Ходоки уходят без тела).
- **Квадрат:** сменщик Оператора не держал протоколы → Бледный слышит, что звук отражается по сетке (квадрат/куб). Комната → веранда (кофе, сигарета) → поле → Лес → холмы → Сид. Мир как одна комната. Отсылка: тест решётки Бина–Давуди–Сэвиджа.
- Под холмами в Сиде, где когда-то уменьшил [[Крёстная|Крёстную]]: вместо красных кристаллов — обрыв, пустота, грани Многогранника.
- Нора Саары шарообразная, ракушки по золотому сечению → эхо круглое, сетки нет.
- **Отложено до Лозанны:** звуки в реальном мире разные, не сэмплы/спрайты.

Мем: Квадрат — «мир звучит по сетке». См. [[Пять мемов]], [[Склейки]].
