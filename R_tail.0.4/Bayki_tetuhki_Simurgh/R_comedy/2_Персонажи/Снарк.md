# Снарк

**Роль:** мистер Голд из «Револьвера». Эго [[Рыжий|Рыжего]].

- Рыжий считает себя Снарком — автором, проснувшимся в чужой симуляции. Это и есть его Голд: гордыня «я создатель».
- Отсылка: Кэрролл, «Охота на Снарка». Финал Снарка — Буджум (кто встретил, тот исчезает).
- Эпиграф арки — Рыжий говорит **своему эго** (см. [[Арка Рыжего]]).

## Правила голоса (рабочие)
1. Слышит только Рыжий. Курсив, без кавычек.
2. Говорит «мы», маскируется под Рыжего.
3. Давит на три точки: страх смерти, деньги/ценности, «ты создатель».
4. Полуправда — всегда частично прав.
5. Громче на подъёме SALVIA, молчит в амнезии финала.
6. Слабеет, когда Рыжий делает что-то без выгоды.
- Иногда идёт **без курсива** — Рыжий принимает за свою мысль. Пример: «Слушай, в конце концов, я старший».

Маски Голда в сюжете: [[Семполия Лилич]] (голос, через нарколепсию/Покой), [[Зион]] (лицо на Пике). Над всеми — [[Симург]].
