# Ральф Первый

- Воспитатель из Дома. Сейчас — по контракту держит роль [[Тарантул]]а (смотритель дома на грани миров).
- Согласился, потому что ему предложили [[Крёстная|Крёстную]].
- Один из интересов [[Симург]]: ей интересен его **сценарий**. догадка: сценарий «Почти» (Берн) — всю жизнь у двери, не доходит.
- Получает [[Тайный дневник Кристины]] (перепутала). Склейка — **чёрные страницы**. Видит свой портрет углём с брошкой Инквизиции.
- **Получит должность инквизитора** (после события с Невозможной Вещью — дневником).
- догадка: он и есть инквизитор над [[Янус]]ом.

Мем: Порог — «аномалия опасна, держи дверь закрытой». См. [[Пять мемов]].
