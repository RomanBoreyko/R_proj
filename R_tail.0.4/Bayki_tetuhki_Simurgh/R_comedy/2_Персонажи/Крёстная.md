# Крёстная

Кристина Тарантулова. Бывший директор Дома.

- Бледный заманил её под холмы (Сид), там время течёт иначе → помолодела до ребёнка. Осталась на Изнанке, с [[Ральф Первый|Ральфом]].
- **Детство:** матери нет. Живёт в доме [[Тарантул]]а (мозгоправ, принимает на дому). В подвале пахло газом — любила играть. Галлюцинации, звон, говорила с **ангелом** (= [[Симург]]): никогда не показывался, не оставлял памяти о себе, просил рассказать о нём миру. Писала про культистку Люричеву, [[Омут]], кватернионы, живую математику.
- **Записки ангела:** её почерк, но ровнее; бумага из её тетради. Задания: Омут, Люричевы, «поворот без оси». Канал с детства.
- **Дереализация.** Слуха Бледного нет — замечает другое (масштаб, документы).
- **Два дневника:** показной (для Ральфа, на виду) и тайный (в подвале). Подвал = [[Склейки|Склейка]]: тьма вместо пространства; дневник исчезает из рук, в памяти вклеивается «спустилась, положила». Бэкдор Симург.
- Уходя по поручению ангела, **перепутала дневники** → тайный достался Ральфу. См. [[Тайный дневник Кристины]].
- Плата Ральфу за должность Тарантула.

Мем: Омут — «числа живые, поворот без оси». См. [[Пять мемов]].
